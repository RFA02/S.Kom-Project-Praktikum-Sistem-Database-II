### Fungsi
Secara umum, web ini memiliki dua fungsi utama:

1. **Menyelamatkan makanan surplus (*Food Rescue*)**
   
   Bisnis seperti restoran, café, bakery, dan warung dapat mengunggah makanan yang masih layak konsumsi tetapi berpotensi tidak terjual. Makanan tersebut dapat ditawarkan kepada konsumen dengan harga diskon sebelum akhirnya menjadi *food waste*. Konsumen dapat melihat makanan surplus yang tersedia, melakukan reservasi, dan mengambil makanan sesuai dengan waktu yang telah ditentukan oleh bisnis.

2. **Membantu mencegah surplus (*Food Waste Prevention*)**
   
   Web menyimpan data produksi dan penjualan makanan dari bisnis. Data tersebut dapat digunakan untuk melihat pola penjualan dan memberikan rekomendasi jumlah produksi berdasarkan riwayat penjualan. Dengan demikian, bisnis tidak hanya dapat menyelamatkan makanan yang sudah menjadi surplus, tetapi juga dapat mengurangi kemungkinan terjadinya surplus pada produksi berikutnya.

Dengan menggabungkan kedua fungsi tersebut, web ini membentuk alur **produksi → penjualan → pengelolaan surplus → analisis data**, sehingga makanan yang masih layak konsumsi dapat dimanfaatkan secara optimal dan jumlah makanan yang terbuang dapat dikurangi.
